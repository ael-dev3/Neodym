# 24-Hour Writing Workflow

This folder records how an autonomous daily writing pass should work.

- [`24h-writing-rules.md`](24h-writing-rules.md) — rules for each daily run.
- [`last-run-report.md`](last-run-report.md) — latest completed run.

The cron should make exactly one focused improvement per run: draft, revise, compress, repair continuity, or improve organization. It should then update indexes, counts, changelog, and this report.
