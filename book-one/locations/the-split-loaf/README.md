# The Split Loaf

## Quick Summary
The Split Loaf is a bakehouse, inn, gossip court, shelter in Book One. Begins as shelter; becomes a place that must choose whether shelter is worth punishment.

## Story Function
People buy bread, hide news, argue over risks, and find temporary shelter.
