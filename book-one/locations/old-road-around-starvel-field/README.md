# Old Road Around Starvel Field

## Quick Summary
Old Road Around Starvel Field is a older chapel way / boundary-skirt road in Book One. Becomes the route that lets human truth survive long enough to be heard.

## Story Function
Used by those avoiding watched roads, old chapel traffic, smugglers, and desperate witnesses.
