# Book One Characters

This folder keeps Book One’s cast navigable and prevents named characters from drifting away from the manuscript.

Rules:

- Every named character gets a lowercase kebab-case folder.
- Major and supporting characters get profile, arc, appearances, relationships, voice, visual, and continuity files.
- Minor named characters still get a folder and are marked as active, cut candidate, merge candidate, unresolved, or archived.
- When a chapter draft adds or meaningfully changes a character, update that character folder plus the global indexes.
