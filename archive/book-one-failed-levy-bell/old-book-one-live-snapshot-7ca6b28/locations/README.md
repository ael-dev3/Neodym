# Book One Locations

This folder keeps Book One’s places functional, not decorative.

Rules:

- Major recurring locations get their own folders.
- Each location file should explain what people do there, who controls it, what danger it creates, and how it changes the plot.
- Aurelith contact levels stay low: mostly 0–2 for Book One.
- When a chapter changes how a location works, update its folder plus `location-chapter-index.md`.

Start with:

- [`main-locations.md`](main-locations.md)
- [`location-chapter-index.md`](location-chapter-index.md)
