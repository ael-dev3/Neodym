# Low Wicker

## Quick Summary
Low Wicker is a damp sheep valley / village in Book One. Starts as a place trying to survive quietly; becomes a public witness against a useful lie.

## Story Function
People bake, barter, count debts, read rolls, hide children, gossip, and decide what truth costs.
