# Saint Orra's Chapel

## Quick Summary
Saint Orra's Chapel is a small stone chapel and witness place in Book One. Moves from quiet refuge to a tool Nera must spend publicly.

## Story Function
People swear oaths, bury poor dead, ask for quiet bargains, and seek forms power might respect.
