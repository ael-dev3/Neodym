# Chapter Guides

This folder turns the 12-chapter outline into a maintainable drafting map.

Use these files before drafting or revising:

- [`chapter-index.md`](chapter-index.md) — full chapter-by-chapter guide.
- [`chapter-status.md`](chapter-status.md) — compact word-count and status table.
- Individual chapter guide files — one per planned chapter.

When prose changes, update the relevant guide, status table, character folders, location folders, page budget, changelog, and last-run report.
