# Osa Fen — Visual Description

## Core Visual Identity
broad-shouldered, flour to the elbows, strong arms, face lined by oven heat and worry The visual should feel grounded in mud, wool, road, bread, ash, and human pressure.

## Face
Use specific rural human detail. Avoid perfect fantasy-model symmetry.

## Body / Movement
hard, practical, scolding, reliable when no one calls it charity should shape how they stand, move, and handle tools.

## Clothing
rolled sleeves, heavy apron, dark skirt dusted white, kerchief that never stays clean.

## Hands / Tools / Objects
oven peel, flour arms, blessing cuts in bread.

## Color Palette
flour white, oven red, smoke gray, old wool black.

## Symbolic Motif
Split Loaf oven stones.

## Image Generation Prompt
Grounded high-fantasy character portrait of Osa Fen, owner of the Split Loaf, baker, widow, and Nera’s guardian figure, in rural Low Wicker, tactile wool, mud, bread ash, rain, iron, subdued natural light, emotionally restrained, human-first, no modern clothing, no glossy fantasy armor, no visible Aurelith explanation, painterly realism.

## Negative Prompt
No modern slang visuals, no sci-fi tech, no neon glow, no generic elf styling, no heroic chosen-one pose, no franchise imitation, no clean cosplay fabric.
