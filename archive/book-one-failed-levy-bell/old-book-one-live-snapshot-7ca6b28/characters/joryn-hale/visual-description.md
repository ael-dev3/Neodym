# Joryn Hale — Visual Description

## Core Visual Identity
wet shoulders, tired face, service-stiff posture, badge often sitting crooked The visual should feel grounded in mud, wool, road, bread, ash, and human pressure.

## Face
Use specific rural human detail. Avoid perfect fantasy-model symmetry.

## Body / Movement
decent enough to be trusted and obedient enough to be dangerous should shape how they stand, move, and handle tools.

## Clothing
plain coat with local badge, spear, worn boots, cheap belt.

## Hands / Tools / Objects
crooked badge, spear, looking away first.

## Color Palette
wet brown, dull iron, badge brass, rain-dark wool.

## Symbolic Motif
crooked badge.
